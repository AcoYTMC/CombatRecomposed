# Combat Recomposed:

Combat recomposed add various additions to not CHANGE Minecraft's base combat but to improve upon it in unintrusive ways

## Gear Changes:

- ~~Enchantments now have one universal level.~~
- ~~Armor, tools, and weapons no longer have durability~~
- ~~Netherite will no longer give knockback resistance.~~
- ~~Knockback and thorns enchantment is removed~~
- Mace is unenchantable.

## Mechanic Tweaks

- ~~Fire burn time is lessened.~~
- ~~Mace is a lot rarer~~

## New Additions:

A new umbrella that has normal sword enchants and blocks like a toggleable shield however it also comes with two new enchantments that replace its shield function.

A new enchantment for the umbrella called Strike which allows the player to rush forward damaging any player that the user passes through.
    (This enchant is omnidirectional and can only be used when pressing a movement key and is not compatible with drag).

A new enchantment for the umbrella called Drag, which when the user is holding an umbrella with the enchantment, it will allow them to glide slowly.
Also, if the user looks straight down they can open, and close their umbrella, to release a gust of air that shoots them up a bit
    (they may use this three times, before returning to land to recharge it).
